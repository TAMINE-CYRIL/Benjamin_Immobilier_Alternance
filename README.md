# Découverte de l'utilisation de Crawl4AI

On peut utiliser deux types d'extraction : via le CSS du site, notamment pour un site statique, ou à l'aide d'un modèle LLM (ici Ollama) pour un site plus dynamique. L'objectif est de scrap différents sites d'immobilier, afin d'obtenir des informations sur chaque annonce.
On renvoie un format JSON pour faciliter la lecture et la réutilisation du contenu extrait.
